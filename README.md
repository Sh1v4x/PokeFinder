# PokeFinder

**Une carte, un Pokémon, un numéro.**

Application web simple qui affiche la carte d'un Pokémon en fonction d'un numéro saisi par l'utilisateur, à partir des données de la PokeAPI.

## Fonctionnement

L'utilisateur voit un champ de saisie où il peut entrer un nombre entre 1 et 905. Après avoir saisi un nombre et cliqué sur « SEND », une carte Pokémon correspondante s'affiche. La carte contient des informations sur le Pokémon, telles que son nom, son type, ses statistiques et ses capacités.

## Technologies utilisées

- HTML
- CSS
- JavaScript
- [PokeAPI](https://pokeapi.co/)

## Installation et utilisation

1. Clonez ce repository
2. Ouvrez le fichier `index.html` dans votre navigateur
3. Entrez un nombre entre 1 et 905 dans le champ de saisie
4. Cliquez sur « SEND » pour voir la carte Pokémon correspondante
